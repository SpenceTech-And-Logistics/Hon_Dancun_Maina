# Project photos

Drop photos in this folder, named after the project's ID. They show on the project's card, its page and the Gallery.

- One photo: `mathari-lab.jpg`
- More photos: `mathari-lab-2.jpg`, `mathari-lab-3.jpg` and so on. The first one is the cover.
- `.jpg`, `.png` and `.webp` all work. Keep each photo under about 500 KB (1600 px wide is plenty).

Then `npm run build` and deploy. Photos uploaded in the dashboard still work, and both are shown together.
